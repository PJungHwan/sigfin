# STEP 8 — Crypto × Macro 사후 통계 분석

기존 가격 차트·지표·전략·백테스트·리스크·FRED 조회와 독립적으로 실행한다.
실제 주문, 투자 판단, 예측 모델, 거시 기반 거래 신호를 생성하지 않는다.

## 수집 및 캐시

- 사이드바 BTC/ETH 선택을 재사용하고 전용 실행 버튼에서만 조회한다.
- 분석 기간은 1/3/5/10년, UTC 현재 월의 첫날에서 해당 연수 이전부터 현재까지다.
- 기본 원천 봉은 일봉이다. 5m/15m/1h/4h도 지원하지만 기존 최대 5,000개 봉,
  페이지당 1,000개, 최대 7회 요청 제한을 적용하므로 장기 분석에 부족할 수 있다.
- 가격은 이전 월 기준 종가 확보를 위해 한 달 앞부터, 거시 값은 YoY 분모 확보를 위해
  1년 앞부터 요청한다. CPI 서비스 자체의 추가 워밍업도 기존 정책을 유지한다.
- 기존 `load_market_data`(60초)와 `load_macro_series`(1시간, 자격별 분리) 캐시를 사용한다.
  변환·표시 선택만으로 자동 API 요청하지 않는다. 실행 버튼도 유효한 원천 캐시를 재사용한다.
- 조회 범위·설정·종목·인증 또는 월이 바뀌면 이전 분석 결과를 무효화한다.
  결과는 실행 당시 스냅샷이며 자동 갱신되지 않는다.

## 월 정렬과 수익률

`timestamp`는 UTC 봉 시작, `candle_end = timestamp + timeframe`은 봉 마감이다.
분석 기준 시각 이전 또는 그 시각에 마감된 봉만 사용한다. 예를 들어 9월 30일 일봉은
10월 1일 00:00에 마감하고 9월 월말 종가에 속한다. 월 라벨은 `candle_end - 1ns`로 결정한다.

각 달 마지막 확정 종가 C를 선택하여 `(C_t/C_(t-1)-1)*100`으로 월간 수익률을 계산한다.
첫 달 이전 기준 가격이 없거나 직전 달 자체가 없으면 NaN이다. 전체 달력을 재색인한 뒤
이전 달과 비교하므로 누락 월을 건너뛰어 두 달 수익률을 한 달 수익률로 표시하지 않는다.
달의 실제 봉 수, 예상 봉 수, 마지막 봉 마감 및 전월 기준 종가 존재 여부로 부분 월을 판정한다.
기본값은 부분 월 제외다. 현재 진행 월, 조회 경계의 부분 월, 봉 누락이 있는 월은 표시하되
상관계수에서 제외하며, 선택하면 탐색용으로 포함할 수 있다. 결측값은 포함 선택과 무관하게 제거한다.

시간별/일별 수익률은 UTC 고정 구간으로 집계하며 현재와 이전 구간이 모두 완전할 때 계산한다.
일봉에서 시간봉을 생성하는 등 더 작은 주기로 복제하지 않는다.

## 거시 변환과 단위

| 시리즈 | 원본 | 통계에 사용하는 변화 |
| --- | --- | --- |
| CPIAUCSL | 지수, 1982–1984=100 | MoM `(CPI_t/CPI_(t-1)-1)*100`, 또는 YoY `(CPI_t/CPI_(t-12)-1)*100`, % |
| FEDFUNDS | 월평균 연방기금금리, % | 전월 차이, %p |
| UNRATE | 실업률, % | 전월 차이, %p |
| PAYEMS | 비농업 고용 총수준, 천 명 | 전월 차이, 천 명 |
| DGS10 | 일별 10년물 금리, % | 월말 마지막 유효 관측 또는 월간 유효 관측 평균의 전월 차이, %p |

FRED 월초 관측 라벨을 해당 관측 월로 변환한다. 원본 관측일, 단위 및 주기를 검증한다.
월 달력을 먼저 복원하고 차분하므로 누락 월을 건너뛰지 않는다. CPI 분모가 0 이하이거나
필요한 이전 월/전년동월 값이 없으면 NaN이다. DGS10의 월말 값은 마지막 유효 관측이며
원본 결측값 개수와 집계 표본 수를 별도로 표시한다. 일별 변화는 직전 관측 행 차이이며,
명시적 결측 행을 건너뛰지 않는다. 주말/휴일을 생성하거나 발표일을 추정하지 않는다.

## 상관관계·시차

월 수익률과 선택한 거시 변화의 유한한 공통 값만 사용한다. 최소 표본은 기본 12개월,
부족하거나 상수이면 N/A이다. 결측 제거 전·후 표본과 실제 표본 기간을 기록한다.
Pearson은 중심화된 벡터 내적/노름, Spearman은 동률의 평균 순위에 대한 Pearson이다.
결과는 [-1,+1] 범위를 검증한다. p-value나 통계적 유의성을 계산하지 않는다.
36개월 미만 경고는 탐색용 안내 기준이며 그 이상이 안정성이나 예측력을 보장하지 않는다.

lag k는 **거시 t월 변화와 암호화폐 t+k월 수익률**이다 (k=0,1,2,3).
캘린더 월 인덱스로 이동하고 각 쌍의 거시 원천 월/가격 목표 월/유효 여부를 기록한다.
각 lag는 동일한 거시 변환을 사용하고 개별 표본 수·거시 표본 시작/종료 월을 표시한다.
목표 가격 월이 부분 월이면 그 lag에서도 기본 제외한다. 달을 압축하거나 마지막 값을 순환하지 않는다.
미래 목표 수익률은 사후 통계용 표본 표에만 있으며 과거 입력 특징이나 전략으로 내보내지 않는다.
여러 시차 비교에는 선택 편향/다중 비교 위험이 있고 최고 계수만으로 투자 전략이 검증되지 않는다.

수준 차트는 첫 공통 유효 월=100으로 기준화한다. 기준월 거시 값이 0 이하이면 거시 선을 제외한다.
가격과 %·지수·천 명 원본을 같은 축에 섞거나 서로 더하지 않는다. 상관계수는 수준 차트가 아닌
변화값으로 계산한다.

## 공개 시점과 빈티지

기본 A는 **현재 개정된 FRED 값에 대한 사후 탐색**이다. 관측일은 발표일이 아니며
동일 관측 월에 해당 수치가 공개되어 있었다고 가정하지 않는다.
`release_date`, `available_at`, `vintage_date`는 기존 미확인 상태를 유지한다.
`realtime_start/end`나 수집 시각을 발표 시각으로 대체하지 않는다.
현재 B는 UI 실행 불가이고 순수 분석/서비스에서도 `PointInTimeUnavailable`을 발생시킨다.
임의의 메타데이터를 채워도 우회 실행할 수 없다. 신뢰 가능한 발표 시각과 당시 빈티지의
출처 검증·정렬 경로를 별도 구현하기 전에는 시점 준수 결합을 허용하지 않는다.
거시 forward-fill, 과거 백테스트 입력, 인과/실시간 예측 성능 주장은 구현하지 않는다.
