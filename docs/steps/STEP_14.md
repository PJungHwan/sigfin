# STEP 14 — 가상 포트폴리오 관리

## 개발 목표

확정 로드맵의 USDT 가상 현금/BTC·ETH 양수 보유·수동 매수/매도를 구현한다. 기존 백테스트·Agent가 거래를 자동 생성하지 않도록 분리한다.

## 구현한 기능·계산 기준

- 초기금 기본 10,000 USDT. 계좌/거래/가격 모델은 유한 숫자·UTC·지원 자산만 허용한다.
- 이동 수량 가중평균 체결가, 여러 번 매수·일부/전체 매도·수수료/불리한 슬리피지.
- 모든 지급 수수료를 계좌 실현 손익에 포함한다. 미실현은 보유량×(확정 종가−평균 체결가)이며 비용을 다시 차감하지 않는다.
- `총자산 = 현금 + 보유 평가액 = 초기금 + 실현 + 미실현`을 검증한다. 현금 부족/초과 매도·중복 ID 내용 변경·미래/오래된 가격을 거부한다.
- 원장 이벤트만 원본이며 replay로 재검증한다. 계산은 입력 계좌/가격을 변경하지 않는다. 동일 ID/동일 내용은 중복 반영하지 않는다.
- 정밀도는 Python IEEE-754 float를 유지하고 계산 중 표시용 반올림을 하지 않는다. 회계 등식 허용오차는 절대 `1e-8` USDT/상대 `1e-10`이며 UI 금액/수량 표시 자릿수와 분리한다. 음수 잔고/초과 매도를 허용오차로 허용하지 않는다.
- 기존 캐시를 재사용하는 명시적 BTC/ETH 가격 조회와 공통 확정 마감 평가. 누락 가격이면 총자산/미실현은 N/A로 표시하고 원장을 보존한다.
- 세션 원장·수동 입력 폼/확인·초기화 확인·보유/가상 거래 내역. 재실행/지표 토글은 거래를 생성하지 않는다.

## 사용 기술

Python 3.11, pandas, 기존 Pydantic StrictModel, Streamlit 폼/세션, 기존 `adverse_fill_price`/시장 데이터 캐시. 새 패키지는 추가하지 않았다.

```powershell

```
