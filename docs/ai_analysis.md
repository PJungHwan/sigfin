# STEP 9 — 단일 LLM 시장 분석

## 실행

프로젝트 가상환경에서 `python -m pip install -r requirements.txt` 후
`python -m streamlit run app.py --server.port 8503`으로 실행한다.
이미 사용 중인 포트라면 다른 포트를 지정한다. 기본 모드는 **Mock Mode**이며
실제 시장 입력에 대해 테스트용 가상 응답을 구성한다. 실제 LLM의 분석/성능/예측이 아니다.
시장 데이터를 만들어 대체하는 기능은 없다.

실 API를 사용하려면 프로젝트 `.env`에 본인의 `OPENAI_API_KEY`와 선택적으로
`OPENAI_MODEL=gpt-5.4-mini-2026-03-17`을 설정한다. 키는 Git 제외 대상이며 화면·요청 원장·
분석 입력·로그에 표시하지 않는다. 코드에서 키 발급이나 계정/결제 설정을 수행하지 않는다.
모드 선택 후 비용 안내를 읽고, 현재 설정의 유료 요청 승인 체크박스를 직접 선택한 뒤
**사이드바의 AI 분석 실행 버튼**을 눌러야 요청한다. 설정/키/모델 변경은 동의를 초기화한다.
페이지 새로고침·지표 체크박스·모드 선택·동의 체크 자체는 API를 호출하지 않는다.

모델은 공식 문서에서 Responses/Structured Outputs 지원을 확인한 GPT-5.4 mini의 별칭과
2026-03-17 스냅샷만 현재 허용한다. 다른 모델은 자동 대체하지 않고 지원 미확인 오류로 보류한다.
이는 환경변수를 통해 확인되지 않은 모델/가격으로 비용이 발생하는 일을 막기 위함이다.
계정별 모델 사용 권한과 결제 상태는 실제 유료 호출 없이는 확인하지 못한다.

## 데이터 경로

`services/ai_inputs.py`는 기존 확정 OHLCV/지표 결과를 검증하여 다음 값만 요약한다.

- BTC/ETH, timeframe, UTC 봉 시작/마감, 원본 수집 시각
- 마지막 확정 종가, 시가 대비 종가 변화율, RSI, MACD/Signal/Histogram
- EMA/SMA, Bollinger, 거래량/거래량 평균/비율
- Python에서 계산한 이동평균 간 차이와 최근 연속 20봉 종가 변화
- 누락/부분 수집, 오래된 데이터, 부족한 지표 등의 품질 안내

원시 시계열을 전송하지 않는다. JSON 요약/요청 본문은 최대 24,000 UTF-8 바이트,
출력은 기본 3,000/최대 5,000토큰이다. 핵심 지표가 없거나 유효한 봉이 부족하면 로컬
`INSUFFICIENT_DATA` 결과를 반환하고 유료 요청을 하지 않는다. 유효한 확정 봉 자체가 없으면
데이터 부족을 표시하며 임의 시각/가격으로 리포트를 만들지 않는다.

거시 자료는 기존 FRED 조회를 마친 선택 항목의 데이터만 재사용한다. AI 버튼에서 FRED를
자동 조회하지 않는다. CPI는 원본 지수, FEDFUNDS/UNRATE/DGS10은 %, PAYEMS는 천 명이다.
자료 수집 시각, 관측일, 주기/단위, 현재 개정 스냅샷 정책을 보존한다. 가격 마감일보다
뒤의 관측 라벨은 사용하지 않지만, 이것이 과거 공개 가능성을 입증하는 것은 아니다.
발표 시각/빈티지는 미확인으로 유지한다. Macro는 문맥 설명만 하며 상승/하락 판단 요인에
넣을 수 없다. 사후 상관관계 결과나 현재 개정값을 백테스트/주문 입력으로 보내지 않는다.

## Structured Outputs와 내용 검증

공식 OpenAI Python SDK의 `responses.with_raw_response.parse(text_format=AnalysisReport)`를
사용한다. 이는 `responses.parse`의 원본 HTTP 래퍼이며, 파싱 실패 전에 보고된 토큰 사용량을
보존하기 위한 것이다. Pydantic 출력 스키마는 필수 필드·enum·수치 유한성·문장/배열 길이를
검증하고 추가 필드를 거부한다. 출력 모델에는 confidence/성공 확률/예상 승률이 없다.
`store=False`, `reasoning.effort=none`이며 외부 도구나 비공개 추론 출력을 요청하지 않는다.

JSON 형식 검증만으로 사실성을 보장하지 않는다. Python에서 값·시각·단위와 **검증 가능한
근거 문장 목록**을 생성한다. LLM은 이 목록에서 상승/하락 요인을 선택하고, 허용된 한국어
요약/결론 문장을 조합한다. 자유로운 사건 서술이나 새로운 숫자 생성은 허용하지 않는다.
이는 표현력을 제한하지만 입력에 없는 사건이 한국어 서술로 통과하는 문제를 줄인다.

후속 `llm/validators.py` 검증:

- 종목/주기/요청 분석 시각/가격 자료 마감과 정확히 대조
- 근거 reference ID, source, metric, 날짜, 설명을 원본과 대조
- 수치는 원본과 절대 오차 1e-10 이내인지 확인하고 비유한 값 거부
- 선택된 모든 요인에 해당 evidence 존재 여부, 가격/선택 Macro 근거 포함 여부
- 상충하는 근거 누락, Macro를 방향 요인으로 사용하는 경우 거부
- 요약/결론/위험/한계가 허용된 문장인지 확인
- 데이터 충분성 및 방향별 최소 근거 확인

형식이 올바르더라도 위 검증에 실패하면 AI SIGNAL에 결과를 표시하지 않는다.
이 검증은 입력 정합성 검사이며 투자 판단의 정확성·인과관계·예측 성능을 입증하지 않는다.

## 비용·재시도·오류

가격은 `config/llm_settings.py`에서 별도 관리한다. 2026-10-15 공식 표준 가격 확인 기준
입력 $0.75 / 출력 $4.50 per 1M tokens다. 캐시 할인/세금/실제 청구 조정은 추정에 포함하지 않는다.
가격 미등록 또는 확인 후 30일 초과 시 '미확인'으로 표시하고 비용 상한 검사 불가로 실 요청을
보류한다. 최신 공식 가격을 확인한 뒤 설정을 갱신해야 한다.

정확한 사전 토큰 수를 만들어 표시하지 않는다. 요청 본문·Structured Outputs 스키마의 UTF-8
바이트 수와 프레이밍 여유를 보수적인 예약 추정에 사용한다. 요청 직전 예약 비용과 요청 후
API가 보고한 input/output/total tokens에 따른 추정 비용을 구분한다. 청구 확정액이 아니다.
사용자가 설정한 세션 요청 횟수·추정 비용 상한을 서버 측에서도 검증한다. SDK 자동 재시도는
0회, 사용자가 선택한 경우 Rate Limit/서버 오류에 대해서만 추가 1회를 허용하며 매 시도마다
횟수/비용을 별도 예약한다. 인증/타임아웃/연결/검증 오류는 자동 재시도하지 않는다.

각 실 API 시도는 실행 전에 원장에 기록한다. 실패하거나 사용량을 받지 못한 경우 무료로
간주하지 않고 예약 비용을 유지한다. JSON/내용 검증 실패라도 사용량이 있으면 기록한다.
진행 중 끊긴 요청은 PENDING/과금 미확인으로 남아 예약을 유지한다. 같은 입력/모드/모델/키의
중복 요청은 60초간 차단한다. 예산 검사 단계에서 거부된 미전송 요청은 중복 잠금하지 않는다.

세션 원장과 동시 실행 잠금은 브라우저 세션 단위다. 새 세션/서버 재시작 시 초기화되며,
공유 계정 전체의 지출 상한이나 OpenAI 결제 대시보드를 대체하지 않는다.

인증·권한·Rate Limit·네트워크·타임아웃·API 상태·불완전 출력·거부·스키마·근거 오류를
분리한다. 원본 오류 본문/인증 헤더/키는 UI에 출력하지 않는다. 공식 API 주소만 사용한다.

## 결과 무효화와 범위

결과는 세션 안에서만 유지한다. 종목/봉/기간/입력 값/수집 시각/선택 Macro/모델/키/AI 설정이
바뀌면 이전 결과를 무효화한다. 표시용 기술지표 체크박스는 재호출하지 않는다.
기존 Agent 상태 카드는 향후 연결 예정인 상태로 유지한다. 이번 단계는 단일 LLM이며
LangGraph, 토론, AI Risk Manager, 주문, 백테스트 수익률 변경을 구현하지 않는다.

## 검증 방식과 공식 근거

`tests/test_ai_analysis.py`: 합성 입력·계산/근거·요청 게이트·예산 테스트.
`tests/test_ai_client.py`: 공식 SDK를 `httpx.MockTransport`에 연결한 Structured Outputs 파서와
인증/권한/타임아웃/Rate Limit/출력 오류 테스트. 네트워크나 결제 API를 사용하지 않는다.
`tests/test_ai_ui.py`: AppTest 버튼/동의/캐시/무효화/Mock/카드 렌더링 테스트.
실제 OpenAI API는 사용자 승인을 받지 않아 호출하지 않았다. 계정 접근성·응답 품질·실제
과금은 미검증이다. 기존 Binance/FRED 데이터를 사용한 Mock 실행은 LLM 실 API 검증이 아니다.

- [GPT-5.4 mini 지원 API·스냅샷·가격](https://developers.openai.com/api/docs/models/gpt-5.4-mini)
